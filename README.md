# DevOps Portfolio

A responsive, dependency-free portfolio website built with HTML, CSS, and JavaScript.

## Preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
